# 노천극장 대기 와이어프레임

축제 플랫폼의 **노천극장(Stage) 대기 기능** 연결 와이어프레임만 공개하는 저장소입니다. 이 저장소는 구현 현황·진행률을 추적하지 않고 기기별 화면 흐름 와이어프레임만 관리합니다.

- 랜딩: https://khu-adelante-26-2.github.io/stage-implementation-status/
- 연결 와이어프레임: https://khu-adelante-26-2.github.io/stage-implementation-status/wireframes.html
- 표시 범위: 게이트 앞 대기 등록 iPad, 사용자 휴대폰 대기 현황, 게이트 운영진 휴대폰

## 노천극장 대기의 전제

- 노천극장 대기는 무거운 좌석 관리가 아니라 **안전을 위한 최대 수용 인원 관리**가 목적입니다.
- 그래서 시스템은 정원·현재 인원 같은 **현장 상태를 들고 있지 않고 대기 순서만** 관리합니다. 정원 판단은 현장 운영진이 직접 합니다.
- 취소는 사용자 본인과 운영진 모두 별도 비밀번호 없이 할 수 있습니다(운영진은 관리자 휴대폰에서 처리).
- 호출 후 **15분**이 지나면 자동으로 미도착(NO_SHOW) 처리되며, 이 시간은 고정입니다.

## 원본과 관리

- 공개 HTML 원본은 이 저장소의 `wireframes.html`입니다.
- 와이어프레임은 원본 개발 저장소의 `update-stage-wireframes` 절차로 갱신합니다.
- 저충실도 와이어프레임이며 실제 UI·색상·문구를 확정하지 않습니다. 등록·호출 시 카카오 알림톡이 정상 발송된다는 가정으로 흐름을 그렸습니다.
- 공개 페이지에는 실제 연락처, 내부 계정, 비공개 URL, 운영 데이터를 넣지 않습니다.

`main`에 push하면 GitHub Pages 워크플로(`.github/workflows/pages.yml`)가 정적 페이지를 배포합니다.
